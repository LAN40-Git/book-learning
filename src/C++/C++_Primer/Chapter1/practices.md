### 1.14

| 维度       | for 循环                         | while 循环                   |
| ---------- | -------------------------------- | ---------------------------- |
| 使用场景   | **循环次数已知，遍历序列**       | **循环次数未知，按条件退出** |
| 三要素位置 | 全部集中在头部                   | 分散在循环外、循环体内       |
| 优点       | 简洁，不易死循环，可读性好       | 灵活，适配动态条件           |
| 风险点     | 复杂 break/continue 容易打乱迭代 | 极易忘记更新变量→死循环      |
