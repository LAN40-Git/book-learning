### 2.1

```
1. short、int、long、long long：都是整型，主要区别是占用内存大小不同，从而表示的数值范围不同。short 最小，long long 最大；long 的字节数随操作系统平台变化。
2. 无符号与带符号：带符号类型可以表示正数、负数；无符号类型只能表示非负数，同等字节下无符号的最大值更大。两者混用容易产生隐式转换 bug。
3. float 与 double：float 单精度占 4 字节，有效数字 6‑7 位；double 双精度占 8 字节，精度更高、表示范围更大，C 中小数常量默认为 double。
```

### 2.2

```
1.利率：double
利率为小数，贷款计算对精度要求高，double双精度浮点数，有效数字 15‑16 位，相比float可以减少计算累积误差。
2.本金：double
贷款金额很大，存在元角分小数，double 可以存储大额带小数的数值。
补充：真实金融软件一般不用浮点，改用long long，将单位换算为 “分”，用整数运算彻底规避浮点精度丢失。
3.付款（每期还款）：double
每期还款额带有小数，需要浮点运算，选用 double 保证计算结果准确。
```

### 2.14

1. 外层作用域：`i=100`，`sum=0`。
2. for 循环头里`int i = 0`，是**循环局部变量 i**，只在 for 循环内部生效，屏蔽外部的 i。

### 2.19

| 对比维度         | 指针（pointer）                          | 引用（reference）                                            |
| ---------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **初始化**       | 可以不初始化，可以后期再指向对象         | **定义时必须初始化**，必须绑定一个已有对象，不能为空         |
| **能否改变绑定** | 指针可以重新赋值，指向另一个不同对象     | **一旦绑定某个对象，永远不能再绑定别的对象**，赋值只是修改绑定对象的值 |
| **是否可以为空** | 可以为空指针`nullptr`，不指向任何对象    | **不存在空引用**，引用必须绑定有效对象                       |
| **内存开销**     | 指针本身是变量，占用内存，存放对象的地址 | 引用是对象的别名，**没有独立内存**，编译器一般不额外开辟空间 |
| **使用语法**     | 通过`*`解引用访问对象，`&`取地址         | 直接使用，不需要解引用，用法和普通变量几乎一样               |
| **多级能力**     | 支持多级指针（`int**`）                  | 不支持引用的引用，可存在指针的引用                           |

### 2.31

| 语句       | 是否合法 | 解析（顶层 / 底层 const）                                    |
| ---------- | -------- | ------------------------------------------------------------ |
| `r1 = v2;` | 合法     | `r1`是普通 int 引用，绑定`v1`。`v2`拥有**顶层 const**；作为右值拷贝值时顶层 const 被丢弃，把`v2`的值赋给`r1`所引用的`v1`。没有涉及底层 const。 |
| `p1 = p2;` | 非法     | `p1`：`int*`；`p2`：`const int*`（**底层 const**）。试图把带底层 const 的指针赋值给普通指针，隐式丢弃底层 const，编译报错。 |
| `p2 = p1;` | 合法     | `p2`是`const int*`（底层 const，允许指针本身修改）。`p1`是`int*`，可以转换为`const int*`，**添加底层 const 是允许的**。这里没有丢弃任何 const。 |
| `p1 = p3;` | 非法     | `p3`：`const int *const`，同时顶层 + 底层 const。作为右值，**顶层 const 被剥离**得到`const int*`；依然保留底层 const。赋值给`int*`要丢掉底层 const，禁止。 |
| `p2 = p3;` | 合法     | `p3`右值剥离顶层 const 得到`const int*`；`p2`本身就是`const int*`，底层 const 匹配。丢弃`p3`的**顶层 const**，底层 const 保留，赋值兼容。 |

### 2.38

1. **auto**：根据**初始化表达式的值**推导变量类型，会**忽略引用、顶层 const**；auto 的推导依赖等号右边的初始化值。
2. **decltype(expr)**：直接取**表达式本身的声明 / 表达式类型**，不做值拷贝，完整保留引用、const 属性；**不会执行表达式，只做类型分析**，不需要初始化也可以推导类型。
